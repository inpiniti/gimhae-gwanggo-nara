# 07. 정책 — 개인정보 / 콘텐츠 / 운영 규칙

이 사이트는 **타인의 가게 정보와 사진**을 게시하고 **방문자 댓글(IP 해시)** 을 수집한다. 작더라도 아래 정책이 필요하다.

## 1. 개인정보처리방침 (`/privacy`)

댓글 작성 시 닉네임·비밀번호(해시)·IP(해시)를 수집하므로 개인정보처리방침 페이지가 필요하다. 최소 포함 항목:

- 수집 항목: 닉네임, 비밀번호(암호화 저장), 접속 IP(해시화, 30일 보관), 댓글 내용
- 수집 목적: 댓글 작성/삭제 본인 확인, 스팸 방지
- 보관 기간: 댓글 삭제 시까지 / IP 해시 30일
- 제3자 제공: 없음. 처리 위탁: Supabase(DB/호스팅), Vercel(호스팅)
- 이용자 권리: 댓글 삭제(비밀번호), 문의 연락처
- 개인정보 보호책임자: 사장님 성함/연락처 (**확인 필요**)
- 애널리틱스 사용 시 쿠키/식별자 고지 (Vercel Analytics는 쿠키 없음 → 문구 간단)

푸터에 링크. 관리자 페이지에도 동일 적용.

## 2. 가게(의뢰처) 정보 게시 동의

- 관리자 등록 폼의 `consent` 체크는 **"가게 사장님께 홈페이지 게시 동의를 받았음"** 을 뜻한다. 동의 없이 공개 불가(DB CHECK).
- 동의 방식: 작업 계약/영수증에 한 줄 문구 + 구두 확인으로 충분. 권장 문구:
  > "시공 사진과 상호·주소는 광고나라 홈페이지(사이트 URL)에 시공 사례로 게시될 수 있으며, 요청 시 즉시 내립니다."
- 전화번호는 **가게가 원할 때만** 게시 (`phone` nullable). 기본은 미게시로 안내.

## 3. 게시 중단 요청 처리

| 단계 | 내용 | 기한 |
|---|---|---|
| 1 | 가게 사장이 전화/카카오톡으로 요청 | — |
| 2 | 관리자에서 해당 Work **비공개** 전환 → 페이지 404, sitemap 제외 | 당일 |
| 3 | 요청 시 완전 삭제 (사진 Storage 포함) | 당일 |
| 4 | 구글 캐시 제거가 급하면 Search Console → 삭제 요청 | 필요 시 |

## 4. 사진 콘텐츠 규칙

- **사람 얼굴이 식별되는 사진은 게시하지 않는다** (초상권). 불가피하면 모자이크.
- 차량 번호판, 타인 매장 간판이 크게 잡힌 사진은 피한다.
- 작업 사진의 저작권은 광고나라에 있음을 `/about` 또는 푸터에 표기. 무단 사용 금지 문구.
- 타사 브랜드 로고(프랜차이즈 간판 등)는 시공 사례로 게시 가능하지만, 해당 본사 요청 시 내린다.
- 업로드 시 EXIF(GPS) 자동 제거 (06-operations 7절).

## 5. 댓글 운영 규칙 (`/privacy` 하단 또는 댓글 폼 안내)

- 삭제/숨김 대상: 광고·홍보, 욕설·비방, 개인정보 노출, 타 업체 비방, 동일 내용 반복.
- 사장님 답글은 "광고나라" 뱃지로 구분. 일반 방문자가 "광고나라"라는 닉네임을 쓰면 뒤에 `(방문자)`를 자동 부착해 사칭을 막는다.
- 본인 비밀번호 분실 시: 관리자가 확인 후 삭제 가능 (연락처로 문의).

## 6. 표기 의무 (푸터)

- 상호, 대표자명, 사업자등록번호, 주소, 전화 — 전자상거래(판매)는 없어 통신판매업 신고 표기는 불필요하지만, 업체 신뢰를 위해 **사업자등록번호 표기 권장** (**확인 필요**: 사장님 동의).
- 저작권 표기: `© {year} 김해 광고나라`.
