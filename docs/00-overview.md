# 00. 프로젝트 개요 — 김해 광고나라

## 1. 배경

- **업체명**: 김해 광고나라
- **업종**: 간판·현수막·LED·실사출력·명함·전단지·스티커·유리 시트지(썬팅) 등 종합 인쇄·옥외광고
- **연락처**: ☎ 055-338-5204 / 010-9399-5204
- **주소**: 경상남도 김해시 활천로36번길 20-1 (확인 필요)
- 예전에 검색되던 홈페이지가 현재는 사라진 것으로 보임 → 새로 제작

## 2. 핵심 컨셉

> **"광고나라에 작업을 맡기면, 그 작업물이 홈페이지에서도 광고가 된다."**

- 광고나라가 시공한 작업(간판, 현수막, 썬팅 등)을 **의뢰한 가게 단위**로 등록한다.
- 등록된 가게는 홈페이지의 **지도**와 **테이블**에 노출되고, 클릭하면 **상세 패널**에 상호·연락처·주소·작업 내용·사진이 표시된다.
- 아주 작은 현수막 하나를 맡겨도 홈페이지에 올라간다 → 고객(가게 사장님) 입장에서 **무료 온라인 노출**이라는 부가 가치.
- 각 작업물 상세 페이지는 **구글 검색에 노출**되어야 한다 (예: "김해 OO식당 간판" 검색 시 노출).
- 방문자는 작업물에 **댓글**을 남길 수 있다.

## 3. 목표

| 구분 | 목표 |
|---|---|
| 비즈니스 | 광고나라의 포트폴리오 전시 + 신규 문의 유도 + 기존 고객 가게 홍보 |
| 사용자 | 지도/테이블로 "우리 동네 어디에 어떤 작업을 했는지" 한눈에 보기 |
| 기술 | 단순한 구조, 유지비 거의 0원, 사장님 혼자 작업물 등록 가능 |

## 4. 주요 화면

### 4.1 메인 (`/`)

```
┌──────────────────────────────────────────────────────────────┐
│  로고 · 김해 광고나라   [지도] [테이블]   검색 ▢  카테고리 ▾   ☎ 055-338-5204 │
├─────────────────────────────────────┬────────────────────────┤
│                                     │                        │
│   지도 (mapcn / MapLibre)            │  상세 패널             │
│   - 작업 가게 마커                    │  - 상호명              │
│   - 클러스터링                        │  - 전화번호 / 주소      │
│   - 마커 클릭 → 오른쪽 상세            │  - 작업 종류 태그       │
│                                     │  - 간략 설명            │
│   ─── 또는 토글 ───                   │  - 작업물 사진 갤러리    │
│                                     │  - 댓글                │
│   테이블 (shadcn/ReUI DataGrid)       │  - [상세 페이지로 →]    │
│   - 상호 / 종류 / 주소 / 작업일         │                        │
│   - 정렬 · 필터 · 검색                 │                        │
│   - 행 클릭 → 오른쪽 상세              │                        │
└─────────────────────────────────────┴────────────────────────┘
```

- 좌측: **지도 ↔ 테이블** 토글 (같은 데이터, 다른 뷰).
- 우측: 선택된 작업물 **상세 패널**. 아무것도 선택 안 됐을 때는 업체 소개/연락처 표시.
- 모바일: 좌측 뷰 전체 화면 + 상세는 바텀시트 또는 전체 페이지로 이동.

### 4.2 작업물 상세 (`/works/[slug]`)

- 독립 URL을 가진 **SEO용 정적 페이지**.
- 메인에서 클릭 시엔 패널로, 검색엔진/직접 링크로 진입 시엔 전체 페이지로 렌더 (Next.js Intercepting Routes).
- 내용: 상호명, 전화번호, 주소(+소형 지도), 작업 종류, 설명, 사진 갤러리, 댓글.

### 4.3 관리자 (`/admin`)

- 사장님 전용 로그인.
- 작업물 등록/수정/삭제, 사진 업로드, 주소 → 좌표 변환, 댓글 관리(삭제/숨김).

### 4.4 업체 소개 (`/about`) — 선택

- 연락처, 오시는 길, 취급 품목, 문의 방법(전화/카카오톡 채널).
