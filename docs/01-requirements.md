# 01. 요구사항

## 1. 기능 요구사항

### FR-1. 작업물(가게) 목록 — 지도 뷰
| ID | 내용 | 우선순위 |

| FR-1.1 | mapcn(MapLibre) 지도 위에 작업 가게를 마커로 표시 | 필수 |

| FR-1.7 | 마커 아이콘/색상을 카테고리별로 구분 | 권장 |

## 2. 비기능 요구사항

| 구분 | 요구사항 |
|---|---|
| **SEO** | 상세 페이지 정적 생성(SSG/ISR), 메타태그, OG 이미지, JSON-LD, sitemap.xml, robots.txt. 상세는 [03-seo.md](./03-seo.md) |
| **성능** | LCP < 2.5s (모바일). 이미지 `next/image` + WebP + 지연 로딩. 지도는 클라이언트 전용으로 dynamic import |
| **반응형** | 모바일 우선. 375px ~ 1920px |
| **접근성** | 키보드로 테이블 탐색 가능, 이미지 alt 필수(SEO 겸용) |
| **비용** | 월 0원 목표: Vercel Hobby + Supabase Free + CARTO 무료 타일. 트래픽 증가 시 유료 전환 |
| **운영** | 사장님 혼자 관리. 관리자 UI는 최대한 단순하게 |
| **보안** | RLS로 공개 데이터만 anon 읽기. 쓰기는 서버 액션 경유. 댓글 비밀번호는 해시 저장 |
| **개인정보** | 가게 정보는 사업자 공개정보이지만, 등록 시 고객 동의 체크(관리자 폼에 체크박스). 비공개 요청 시 즉시 비공개 처리 |
| **백업** | Supabase 자동 백업 + 주기적 CSV export |
