# 08. 디자인 가이드

## 1. 톤 앤 매너

- **"동네 간판집"의 신뢰감 + 깔끔한 포트폴리오**. 화려한 랜딩이 아니라 지도·표·사진이 주인공.
- 사진이 콘텐츠이므로 UI 크롬은 최소화: 흰 배경, 얇은 경계선, 한 가지 포인트 컬러.
- 문구는 해요체, 짧게. 전문용어(채널간판, 파나플렉스 등)는 설명에서만.

## 2. 토큰

| 항목 | 값 |
|---|---|
| 폰트 | **Pretendard Variable** (self-host, `font-display: swap`), 숫자는 `tabular-nums` |
| 기본 크기 | 15px 본문 / 13px 보조 / 20px 제목 / 24px h1 |
| 포인트 컬러 | `--primary`: 광고나라 로고색 (없으면 `#e11d48` 계열 레드 — 간판 업종의 활력) |
| 중립 | shadcn `zinc` 스케일 |
| radius | `0.5rem` (shadcn 기본) |
| 그림자 | 패널·카드 `shadow-sm`, 라이트박스만 `shadow-xl` |
| 카테고리 색 | `docs/domain/category/db.md` 시드값. 뱃지 배경 = 색상, 글자 흰색 |
| 다크모드 | 지원 (시스템 따름). 지도 타일도 자동 전환 |

## 3. 레이아웃

### 데스크탑 (≥ 1024px)
```
헤더 56px: [로고] [지도|테이블 토글] [검색] [카테고리 칩…]            [☎ 055-338-5204]
본문: grid-cols-[1fr_420px]  높이 calc(100vh - 56px)
  좌: 지도 또는 테이블 (자체 스크롤)
  우: 상세 패널 (자체 스크롤, 상단 닫기 ✕)
```
- 패널 폭 420px 고정. 1280px 이상에서 480px.
- 선택 없음 → 우측에 업체 소개 카드 + 최근 작업 3개.

### 태블릿 (768–1023px)
- 동일 2단이지만 패널 360px.

### 모바일 (< 768px)
```
헤더 52px: [로고]                    [토글] [☎]
필터 바: 가로 스크롤 칩
본문: 지도 또는 테이블 전체 화면
상세: 하단 Sheet (초기 60vh, 드래그로 95vh) — 뒤로가기로 닫힘
하단 고정: [📞 전화하기] 플로팅 버튼 (Sheet 열리면 Sheet 내부로 이동)
```

## 4. 컴포넌트 상태

| 컴포넌트 | 로딩 | 빈 상태 | 에러 |
|---|---|---|---|
| 지도 | 회색 스켈레톤 + "지도를 불러오고 있어요" | 마커 0개 → 상단 토스트 "조건에 맞는 작업이 없어요" | "지도를 불러오지 못했어요" + [테이블로 보기] |
| 테이블 | 행 스켈레톤 5개 | 일러스트 없이 텍스트 "아직 등록된 작업이 없어요" | 재시도 버튼 |
| 상세 패널 | 제목·사진 스켈레톤 | — | "작업물을 찾을 수 없어요" + [목록으로] |
| 갤러리 | blur placeholder (`next/image` `placeholder="blur"`, 업로드 시 blurhash 생성) | 사진 없음 → 카테고리 아이콘 플레이스홀더 | 깨진 이미지 → 플레이스홀더 |
| 댓글 | 스켈레톤 2개 | "아직 댓글이 없어요. 첫 댓글을 남겨 보세요" | 인라인 오류 문구 |
| 관리자 폼 | 버튼 스피너 + disabled | — | 필드 하단 오류, 상단 요약 |

## 5. 인터랙션 규칙

- 마커/행 클릭 → 패널 열림과 동시에 URL 변경. 패널 닫기 = `router.back()`.
- 지도에서 선택 시 `flyTo` 는 600ms, 선택 마커는 scale 1.25 + 포인트 컬러 링.
- 테이블 행 hover 시 지도의 해당 마커 강조 (양방향 하이라이트) — 권장.
- 라이트박스: 좌우 화살표/스와이프/ESC, 배경 클릭 닫기, 사진 카운터 `3 / 7`.
- 전화 버튼은 항상 `tel:` — 데스크탑에서는 클릭 시 번호 복사 + 토스트.

## 6. 접근성

- 지도는 `role="region" aria-label="작업 위치 지도"`, 동일 데이터가 테이블로 제공되므로 지도 자체의 키보드 접근은 요구하지 않음.
- 테이블 행은 `<a>` 로 감싸 키보드 포커스 가능.
- 색상만으로 카테고리를 구분하지 않음 — 뱃지에 항상 텍스트.
- 대비 4.5:1 이상. 포커스 링 유지.
- 이미지 alt 필수 (SEO 겸용).
