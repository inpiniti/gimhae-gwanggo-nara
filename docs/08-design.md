# 08. 디자인 가이드

## 1. 톤 앤 매너

- **"동네 간판집"의 신뢰감 + 깔끔한 포트폴리오**. 화려한 랜딩이 아니라 지도·표·사진이 주인공.
- 사진이 콘텐츠이므로 UI 크롬은 최소화: 흰 배경, 얇은 경계선, 한 가지 포인트 컬러.
- 문구는 해요체, 짧게. 전문용어(채널간판, 파나플렉스 등)는 설명에서만.

## 2. 토큰 — **토스 디자인 시스템 기준** (`toss-design` 스킬)

`financial-app`, `financial-landing`과 동일하게 토스 토큰을 기본값으로 쓴다. shadcn CSS 변수(`--primary`, `--background` 등)에 아래 값을 매핑한다.

| 역할 | 라이트 | 용도 |
|---|---|---|
| 배경 `--background` | `#f7f9fc` | 페이지 |
| 서피스 `--card` | `#ffffff` | 패널, 카드, 시트, 테이블 |
| 텍스트 `--foreground` | `#191f28` | 제목, 본문 |
| 텍스트 secondary | `#4e5968` | 보조 설명 |
| 텍스트 tertiary `--muted-foreground` | `#8b95a1` | 캡션, 비활성, 테이블 헤더 |
| 구분선 `--border` | `#e5e8eb` | border, divider |
| **포인트 `--primary`** | **`#3182f6`** | CTA(전화하기), 링크, 선택 마커/행, 필터 칩 선택 — **화면당 이것 하나** |
| 경고 `--destructive` | `#f04452` | 삭제, 오류 |
| 성공 | `#03b26c` | 저장 완료 토스트 |
| 주의 | `#ff9500` | 비공개 상태 뱃지(관리자) |

| 항목 | 값 |
|---|---|
| 폰트 | **Pretendard Variable** (self-host, `font-display: swap`), 숫자 `tabular-nums` |
| 타이포 | 제목 20~24px bold · 본문 15~17px regular · 캡션 12~13px · line-height 1.5. 계층은 크기보다 **웨이트**로 |
| radius | 작은 요소 8~12px, 카드/패널/시트 16~24px (shadcn `--radius: 1rem`) |
| 그림자 | `0 2px 8px rgba(0,0,0,0.06)` 한 종류. 라이트박스만 예외 |
| 카테고리 색 | 뱃지·마커 구분용 **보조 색**. 포인트 블루와 겹치지 않도록 시드값 조정 (`docs/domain/category/db.md`). 뱃지는 연한 배경 + 진한 글자(토스 태그 스타일), 마커만 원색 |
| 다크모드 | 지원 (시스템 따름). 토큰만 교체, 지도 타일도 자동 전환 |

포인트 컬러 사용 원칙: 지도 마커는 카테고리 색을 쓰되 **선택된 마커만 `#3182f6` 링**으로 강조. 헤더의 전화번호, 모바일 플로팅 CTA, 링크는 파란색. 레드는 삭제·오류에만.

## 3. 레이아웃

### 데스크탑 (≥ 1024px)
```
헤더 56px: [로고] [지도|테이블 토글] [검색] [카테고리 칩…]            [☎ 055-338-5204]
본문: grid-cols-[1fr_420px]  높이 calc(100vh - 56px)
  좌: 지도 또는 테이블 (자체 스크롤)
  우: 상세 패널 (자체 스크롤, 상단 닫기 ✕)
```
- 패널 폭 420px 고정. 1280px 이상에서 480px.
- 선택 없음 → 우측에 업체 소개 카드 + 최근 작업 3개.

### 태블릿 (768–1023px)
- 동일 2단이지만 패널 360px.

### 모바일 (< 768px)
```
헤더 52px: [로고]                    [토글] [☎]
필터 바: 가로 스크롤 칩
본문: 지도 또는 테이블 전체 화면
상세: 하단 Sheet (초기 60vh, 드래그로 95vh) — 뒤로가기로 닫힘
하단 고정: [📞 전화하기] 플로팅 버튼 (Sheet 열리면 Sheet 내부로 이동)
```

## 4. 컴포넌트 상태

| 컴포넌트 | 로딩 | 빈 상태 | 에러 |
|---|---|---|---|
| 지도 | 회색 스켈레톤 + "지도를 불러오고 있어요" | 마커 0개 → 상단 토스트 "조건에 맞는 작업이 없어요" | "지도를 불러오지 못했어요" + [테이블로 보기] |
| 테이블 | 행 스켈레톤 5개 | 일러스트 없이 텍스트 "아직 등록된 작업이 없어요" | 재시도 버튼 |
| 상세 패널 | 제목·사진 스켈레톤 | — | "작업물을 찾을 수 없어요" + [목록으로] |
| 갤러리 | blur placeholder (`next/image` `placeholder="blur"`, 업로드 시 blurhash 생성) | 사진 없음 → 카테고리 아이콘 플레이스홀더 | 깨진 이미지 → 플레이스홀더 |
| 댓글 | 스켈레톤 2개 | "아직 댓글이 없어요. 첫 댓글을 남겨 보세요" | 인라인 오류 문구 |
| 관리자 폼 | 버튼 스피너 + disabled | — | 필드 하단 오류, 상단 요약 |

## 5. 인터랙션 규칙

- 마커/행 클릭 → 패널 열림과 동시에 URL 변경. 패널 닫기 = `router.back()`.
- 지도에서 선택 시 `flyTo` 는 600ms, 선택 마커는 scale 1.25 + `#3182f6` 링.
- 모든 터치 타깃 ≥ 44px, 인접 버튼 간격 ≥ 8px. 버튼은 클릭 즉시 인라인 로딩.
- 다이얼로그 보조 버튼은 "닫기"(취소 X). CTA 라벨은 결과 그대로: "삭제하기", "저장하기", "댓글 남기기".
- 모바일 상세는 바텀시트, 카테고리 선택(관리자)도 바텀시트 단일 선택 패턴.
- 테이블 행 hover 시 지도의 해당 마커 강조 (양방향 하이라이트) — 권장.
- 라이트박스: 좌우 화살표/스와이프/ESC, 배경 클릭 닫기, 사진 카운터 `3 / 7`.
- 전화 버튼은 항상 `tel:` — 데스크탑에서는 클릭 시 번호 복사 + 토스트.

## 6. 접근성

- 지도는 `role="region" aria-label="작업 위치 지도"`, 동일 데이터가 테이블로 제공되므로 지도 자체의 키보드 접근은 요구하지 않음.
- 테이블 행은 `<a>` 로 감싸 키보드 포커스 가능.
- 색상만으로 카테고리를 구분하지 않음 — 뱃지에 항상 텍스트.
- 대비 4.5:1 이상. 포커스 링 유지.
- 이미지 alt 필수 (SEO 겸용).
