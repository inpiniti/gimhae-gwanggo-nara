# comment — PRD

## 1. 목표
가게 사장·손님·이웃이 작업물에 한마디 남길 수 있게 해서 페이지를 살아있게 만들고, 사장님이 답글로 소통한다. 가입은 없다.

## 2. 유저 스토리
- US-CM1. 의뢰 가게 사장으로서 "간판 잘 나왔어요, 감사합니다" 한 줄을 로그인 없이 남기고 싶다.
- US-CM2. 방문자로서 내가 쓴 댓글을 비밀번호로 지우고 싶다.
- US-CM3. 광고나라 사장님으로서 댓글에 답글을 달고 "광고나라" 표시가 붙길 원한다.
- US-CM4. 광고나라 사장님으로서 광고성/욕설 댓글을 숨기고 싶다.
- US-CM5. 방문자로서 봇 스팸 댓글이 없는 깨끗한 목록을 보고 싶다.

## 3. 기능 요구사항

| ID | 요구사항 | 우선순위 |
|---|---|---|
| CM-1 | 상세(패널/전체) 하단에 댓글 목록, 오래된 순, 닉네임·시간·본문 | 필수 |
| CM-2 | 작성 폼: 닉네임(1~20), 비밀번호(4~20), 내용(1~500), 숨김 honeypot 필드 | 필수 |
| CM-3 | 제출 → 서버 액션 → 성공 시 목록 즉시 갱신(낙관적 UI 불필요, revalidate로 충분) | 필수 |
| CM-4 | 삭제: 댓글의 "삭제" → 비밀번호 입력 다이얼로그 → 검증 실패 시 "비밀번호가 맞지 않아요" | 필수 |
| CM-5 | rate limit 초과 시 "잠시 후 다시 시도해 주세요" | 필수 |
| CM-6 | Owner Reply: 닉네임 "광고나라" 고정 + 뱃지 + 강조 배경 | 권장 |
| CM-7 | 관리자 댓글 페이지: 전체 최신순, 작업물 링크, 숨김/복원/삭제, 답글 | 필수 |
| CM-8 | 숨김 댓글은 공개 목록에서 제외 (자리표시 없음) | 필수 |
| CM-9 | 본문 줄바꿈 유지, 링크 자동 링크화 안 함(스팸 억제) | 필수 |
| CM-10 | Turnstile 옵션 플래그 (`COMMENT_TURNSTILE=1`) | 선택 |
| CM-11 | 새 댓글 알림 (이메일) | 선택 (v2) |

## 4. UX 문구 (해요체)
- 플레이스홀더: "닉네임", "비밀번호 (삭제할 때 필요해요)", "작업에 대한 한마디를 남겨 주세요"
- 성공: "댓글을 남겼어요"
- 오류: "비밀번호가 맞지 않아요", "잠시 후 다시 시도해 주세요", "내용은 500자까지 쓸 수 있어요"
- 빈 상태: "아직 댓글이 없어요. 첫 댓글을 남겨 보세요"

## 5. 수용 기준
- [ ] 닉네임/비번/내용 입력 후 제출 → 2초 내 목록에 표시, 폼 초기화.
- [ ] honeypot 필드 값 채운 요청 → 200 응답이지만 저장 안 됨(봇에게 힌트 주지 않음).
- [ ] 같은 IP 1분 내 4번째 요청 → 거부 메시지.
- [ ] 잘못된 비밀번호로 삭제 → 거부, 올바른 비밀번호 → 삭제.
- [ ] 관리자 숨김 → 공개 페이지에서 즉시 사라짐, 복원 시 재표시.
- [ ] 공개 API/뷰에서 `password_hash`, `ip_hash` 절대 노출 안 됨.
