# category — PRD

## 1. 목표
방문자가 작업 종류로 목록을 걸러 보고, 사장님이 취급 품목이 바뀔 때 직접 항목을 관리한다.

## 2. 유저 스토리
- US-C1. 방문자로서 "간판"만 골라 지도/테이블을 보고 싶다.
- US-C2. 방문자로서 마커 색상만 보고 대략 어떤 작업인지 알고 싶다.
- US-C3. 사장님으로서 새 품목(예: "아크릴 명판")을 추가하고 순서를 바꾸고 싶다.
- US-C4. 사장님으로서 더 이상 안 하는 품목을 숨기되, 기존 작업물은 그대로 두고 싶다.

## 3. 기능 요구사항

| ID | 요구사항 | 우선순위 |
|---|---|---|
| C-1 | 공개 목록 상단에 카테고리 필터 칩 (다중 선택, `?cat=sign,sheet`) | 필수 |
| C-2 | 뱃지 컴포넌트: `name` + `color` 배경 | 필수 |
| C-3 | 지도 마커 색상 = 대표 카테고리 `color` | 권장 |
| C-4 | 관리자: 목록/추가/이름·색상·순서 수정/활성 토글 | 필수 |
| C-5 | `code`는 생성 시에만 입력, 이후 읽기 전용 | 필수 |
| C-6 | 비활성 카테고리는 필터 칩에서 숨기되, 해당 Work 상세에는 여전히 표시 | 필수 |
| C-7 | 관리자 Work 폼의 카테고리 선택은 활성 항목만 | 필수 |

## 4. UX 메모
- 칩 라벨은 "시트지(썬팅)"처럼 병기 그대로 노출 — 사용자가 둘 중 어떤 말을 쓰든 찾도록.
- 색상은 라이트/다크 모두에서 흰 글자 대비 확보(WCAG AA). 초기값은 그 기준으로 선정.

## 5. 수용 기준
- [ ] `?cat=sign,sheet` 접속 시 두 종류만 지도·테이블에 표시.
- [ ] 관리자가 카테고리 비활성화 → 필터 칩에서 사라지고, 기존 작업물 상세엔 뱃지 유지.
- [ ] Work가 참조 중인 카테고리 삭제 시도 → 거부 메시지.

## 6. 비범위
- 카테고리 계층(대분류/소분류)
- 카테고리별 랜딩 페이지 (v2)
