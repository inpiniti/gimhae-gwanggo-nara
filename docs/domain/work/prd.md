# work — PRD

## 1. 목표

방문자가 "광고나라가 어디에 어떤 작업을 했는지"를 지도·테이블로 훑어보고, 하나를 골라 상세(상호·연락처·주소·설명·사진)를 본다. 각 작업물은 구글/네이버 검색으로도 유입된다. 사장님은 작업 후 5분 안에 등록한다.

## 2. 사용자

| 페르소나 | 니즈 |
|---|---|
| 방문자 (예비 고객) | 우리 동네 근처 작업 사례를 보고 품질을 판단, 전화 문의 |
| 의뢰 가게 사장 | 내 가게가 홈페이지에 잘 나와 있는지 확인, 링크 공유 |
| 광고나라 사장님 (관리자) | 현장에서 사진 찍어 바로 등록, 수정, 비공개 처리 |

## 3. 유저 스토리

### 공개
- US-W1. 방문자로서 지도에서 마커를 클릭하면 오른쪽에 그 가게의 작업 내용을 보고 싶다.
- US-W2. 방문자로서 테이블에서 작업 종류로 필터하고 상호명으로 검색하고 싶다.
- US-W3. 방문자로서 지도와 테이블을 전환해도 필터가 유지되길 원한다.
- US-W4. 방문자로서 상세에서 사진을 크게 보고, 전화번호를 눌러 바로 전화하고 싶다.
- US-W5. 방문자로서 상세 링크를 카카오톡으로 공유하면 미리보기(사진·상호명)가 보이길 원한다.
- US-W6. 검색 사용자로서 "김해 OO 간판"을 검색하면 해당 작업물 페이지가 나오길 원한다.

### 관리자
- US-W7. 사장님으로서 상호명·주소·사진·종류만 입력하면 좌표/slug/alt가 자동으로 채워지길 원한다.
- US-W8. 사장님으로서 스마트폰에서 사진을 여러 장 골라 올리고 순서를 바꾸고 대표 사진을 정하고 싶다.
- US-W9. 사장님으로서 가게가 노출을 원치 않으면 버튼 하나로 비공개하고 싶다.
- US-W10. 사장님으로서 저장하면 홈페이지에 바로 반영되길 원한다.

## 5. 수용 기준 (샘플)

- [ ] 지도에서 마커 클릭 → URL이 `/works/{slug}`로 바뀌고 우측 패널에 상세가 뜬다. 뒤로가기 시 패널이 닫힌다.
- [ ] `/works/{slug}`를 새 탭에서 열면 전체 페이지로 렌더되고, JS 비활성 상태에서도 상호·주소·사진이 HTML에 있다.
- [ ] `?view=table&cat=sign` 으로 접속하면 테이블 뷰 + 간판 필터가 적용된 상태로 열린다.
- [ ] consent 미체크 상태에서 공개 저장 시도 → 저장 거부 및 안내 메시지.
- [ ] 관리자가 사진 5장 업로드 → 첫 장이 커버, 각 장 alt 자동 채워짐, Storage에 WebP로 저장.
- [ ] 관리자 저장 후 10초 이내 공개 페이지에 반영.
