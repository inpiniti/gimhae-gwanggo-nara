# geo — PRD

## 1. 목표
사장님은 주소만 치면 핀이 정확히 찍히고, 방문자는 지도가 빠르고 한글로 읽히며, 길찾기 버튼으로 익숙한 지도 앱을 연다.

## 2. 유저 스토리
- US-G1. 사장님으로서 "삼안동 123-4" 정도만 쳐도 후보가 나오고, 고르면 좌표와 동 이름이 자동으로 채워지길 원한다.
- US-G2. 사장님으로서 핀이 살짝 어긋나면 지도에서 드래그로 옮기고 싶다.
- US-G3. 방문자로서 지도 지명이 한글로 보이길 원한다.
- US-G4. 방문자로서 "길찾기"를 누르면 카카오맵/네이버지도가 열리길 원한다.
- US-G5. 방문자로서 지도가 없는 상태(로딩 실패)에서도 목록은 볼 수 있길 원한다.

## 3. 기능 요구사항

| ID | 요구사항 | 우선순위 |
|---|---|---|
| G-1 | 관리자 주소 입력: 디바운스 검색 → 후보 리스트(도로명/지번 병기) → 선택 시 `address`, `address_dong`, `lng/lat` 채움 | 필수 |
| G-2 | 관리자 폼 내 미리보기 지도 + 드래그 가능한 핀 → 좌표 갱신 | 필수 |
| G-3 | 김해 범위 밖 좌표 저장 시 경고 배너 ("김해 밖 위치예요. 맞나요?") | 권장 |
| G-4 | 공개 지도 초기 뷰 = `GIMHAE_DEFAULT_VIEWPORT` | 필수 |
| G-5 | 타일 스타일 URL env 주입, 라이트/다크 대응 | 필수 |
| G-6 | 한글 라벨 검수 → 미흡 시 대체 스타일 적용 (05-open-questions #3) | 필수 |
| G-7 | 상세 "길찾기": 카카오맵, 네이버지도 링크 (모바일은 앱 스킴, 실패 시 웹) | 권장 |
| G-8 | MapLibre 워커 자체 호스팅 | 필수 |
| G-9 | 지도 로딩 실패 시 fallback: "지도를 불러오지 못했어요" + 테이블 뷰 유도 | 필수 |
| G-10 | 지도 컴포넌트 `ssr: false` dynamic import, 스켈레톤 표시 | 필수 |

## 4. 외부 의존성
| 서비스 | 용도 | 키 | 비용 |
|---|---|---|---|
| Kakao Local API | 주소 검색 | 서버 REST 키 | 무료 (일 쿼터 충분) |
| CARTO basemap | 타일 | 없음 | 무료 (비상업 조건 확인 필요 — 상업 사이트이므로 약관 검토 후 필요 시 MapTiler/VWorld) |
| VWorld (대안) | 한국 타일 | 무료 키 | 무료 |

## 5. 수용 기준
- [ ] "활천로36번길 20-1" 입력 → 1초 내 후보 표시 → 선택 시 김해 좌표 및 "삼안동"류 동 이름 채워짐.
- [ ] 핀 드래그 후 저장 → DB 좌표가 드래그 위치와 일치.
- [ ] 네트워크에서 unpkg 차단해도 지도 정상 로드.
- [ ] 다크 모드 전환 시 타일도 다크로 전환.
