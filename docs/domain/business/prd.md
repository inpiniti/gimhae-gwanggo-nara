# business — PRD

## 1. 목표
방문자가 어느 화면에서든 광고나라에 바로 연락할 수 있고, 검색엔진이 "김해 광고 업체"로 정확히 인식한다.

## 2. 유저 스토리
- US-B1. 방문자로서 폰에서 버튼 하나로 전화하고 싶다.
- US-B2. 방문자로서 어디 있는 업체인지, 언제 여는지 알고 싶다.
- US-B3. 방문자로서 카카오톡으로 사진 보내며 견적 물어보고 싶다.
- US-B4. 검색 사용자로서 "김해 간판"을 검색하면 이 업체가 나오길 원한다.

## 3. 기능 요구사항

| ID | 요구사항 | 우선순위 |
|---|---|---|
| B-1 | 헤더: 로고/상호 + 대표 전화 (데스크탑 텍스트, 모바일 아이콘) | 필수 |
| B-2 | 모바일 하단 고정 "전화하기" 플로팅 버튼 (`tel:`) — 관리자 페이지 제외 | 필수 |
| B-3 | 푸터: 상호, 주소, 전화, (사업자번호), © | 필수 |
| B-4 | `/about`: 소개문, 취급 품목(카테고리 활성 목록), 연락처, 영업시간, 오시는 길(소형 지도 + 카카오맵/네이버지도 링크) | 필수 |
| B-5 | `LocalBusiness` JSON-LD를 루트 레이아웃에 1회 삽입 | 필수 |
| B-6 | 카카오톡 채널 버튼 (URL 있을 때만 렌더) | 권장 |
| B-7 | 상세 패널이 비어있을 때(선택 없음) 우측에 업체 소개 카드 | 필수 |
| B-8 | 기본 OG 이미지 (상호 + 슬로건) | 필수 |

## 4. 수용 기준
- [ ] 모바일에서 어느 공개 페이지든 전화 버튼이 보이고 탭 시 다이얼러 열림.
- [ ] Google Rich Results Test에서 `LocalBusiness` 유효.
- [ ] `business.ts` 값만 바꾸면 헤더·푸터·about·JSON-LD가 모두 갱신됨 (중복 하드코딩 없음).

## 5. 비범위
- 관리자 UI에서 업체 정보 편집 (v2 `site_settings`)
- 다국어
- 온라인 견적 폼 (v2)
