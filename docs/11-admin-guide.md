# 11. 사장님용 사용 설명서

> 홈페이지 관리 화면에서 작업물을 올리는 방법이에요. 스마트폰에서도 똑같이 돼요.

## 들어가기
1. 주소창에 **홈페이지 주소/admin** 을 입력해요. (예: `https://사이트주소/admin`)
2. 이메일과 비밀번호로 로그인해요. 한 번 로그인하면 일주일 정도 유지돼요.

## 작업물 올리기 (5분)
1. 오른쪽 위 **새 작업물** 을 눌러요.
2. **상호명** 을 적어요. (예: 홍콩반점)
3. **작업 종류** 를 눌러 골라요. 여러 개 골라도 돼요. (예: 간판 + 시트지)
4. **주소** 칸에 도로명이나 지번을 적고 **주소 찾기** → 나온 주소를 눌러요. 지도에 핀이 찍혀요. 핀이 살짝 틀리면 **끌어서** 옮기면 돼요.
5. **가게 전화번호** 는 가게에서 원할 때만 적어요. 비워도 돼요.
6. **한 줄 요약** 은 검색 결과에 나오는 문장이에요. 동네 + 작업 + 소재를 넣으면 검색에 잘 걸려요.
   - 예: "삼정동 홍콩반점 채널간판 교체, 갈바 프레임 + LED"
7. **사진 올리기** 를 눌러 사진을 여러 장 골라요. 첫 번째가 대표 사진이에요. 순서를 바꾸려면 **대표로** / **위로** 를 눌러요.
   - 사람 얼굴이 나온 사진은 올리지 말아 주세요.
8. **게시 동의** 에 체크해요. 가게 사장님께 "홈페이지에 올려도 될까요?" 하고 확인받은 뒤에 체크하면 돼요.
9. **홈페이지에 공개** 에 체크하고 **저장하기**. 바로 지도에 나타나요.

## 고치기 · 내리기 · 지우기
- 목록에서 **수정** 을 누르면 다시 고칠 수 있어요.
- 가게에서 "내려 달라"고 하면 **비공개로** 를 눌러요. 홈페이지에서 바로 사라지고 자료는 남아 있어요.
- 완전히 지우려면 **삭제하기**. 사진과 댓글도 함께 지워져요.

## 구글에 빨리 뜨게 하기
- 따로 할 일은 없어요. 작업물을 공개하면 사이트맵(`/sitemap.xml`)에 자동으로 들어가고, 구글이 며칠 안에 알아서 가져가요.
- 더 빨리 띄우고 싶으면 구글 검색 콘솔 맨 위 검색창에 작업물 주소를 붙여넣고 **색인 생성 요청** 을 누르면 돼요. (하루 10건 정도 제한)

## 댓글 관리
- 위쪽 **댓글** 탭에서 모든 댓글을 볼 수 있어요.
- 광고나 욕설은 **숨기기**. 손님 댓글에는 **답글 달기** 로 "광고나라" 이름으로 답할 수 있어요.

## 작업 종류 추가
- **작업 종류** 탭에서 새 종류를 추가하거나(예: 아크릴 명판), 안 쓰는 종류는 **숨김** 으로 바꿔요. 이미 등록된 작업물은 그대로 남아요.

## 문제가 생기면
| 증상 | 해결 |
|---|---|
| 로그인이 안 돼요 | 이메일·비밀번호 확인. 계속 안 되면 개발자에게 연락 — 비밀번호를 다시 만들어 드려요 |
| 주소가 안 찾아져요 | "김해시 OO동 123-4" 처럼 시·동을 함께 적어 보세요. 그래도 안 되면 지도에서 핀을 직접 옮겨도 돼요 |
| 사진이 안 올라가요 | 사진 한 장이 10MB 를 넘지 않는지 확인. 스마트폰 원본은 보통 괜찮아요 |
| 저장했는데 홈페이지에 안 보여요 | **홈페이지에 공개** 체크 여부와 **게시 동의** 체크를 확인해 주세요 |
